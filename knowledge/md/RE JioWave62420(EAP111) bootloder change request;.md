?? days

Jio approved Accton to use new uboot for production.
Accton needs to run factory process validation for this new boot loader. ( 3 days)

Because we (Jio and Accton) need to complete above tasks, we strongly suggest to keep current firmware and uboot in the coming production. And based on the estimated schedule, find a best timing to apply the new uboot into the production.
