Hi Jiean
 
The issue on our side was that the FT-GL station was missing after the version update. Before the ECN implementation, there was no FT-GL station in the production process. The FT-GL station is required when updating to the new version. This was an oversight during the process update for the new version.
the affected units were built with the new version but did not pass through the newly required FT-GL station. Therefo.re, the Simba code was not written to the devices.
In the ShopFloor system, only the FT station log (new version), and it does not include the Simba code writing process.
 
The FT-GL station has now been added to the production process,
 so this issue will not happen again. Additionally, the OQC test station is being updated to identify any units that have not gone through the FT-GL station before they proceed to packing.
